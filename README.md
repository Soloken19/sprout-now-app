# Sprout Now App Homepage

Static homepage prototype for the Explore screen.

## Preview locally

### Option 1: open directly (no server needed)

Open `index.html` in your browser.

### Option 2: run a local server (recommended)

Run from the repo root:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open one of these URLs:

- `http://127.0.0.1:4173/`
- `http://127.0.0.1:4173/index.html`

> If `localhost` refuses to connect in your environment, use `127.0.0.1` and make sure the server process is running.

All assets are local (`/assets`) so the preview works even without internet access.
